# After Hours League

A black, responsive landing page featuring the supplied logo with a gentle floating and lighting animation. Includes a pause control and respects reduced-motion preferences. No build tools or dependencies are required.

## Publish on GitHub Pages

1. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and `after-hours-logo.png` to your repository root.
2. Open the repository's Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.

GitHub will show the published URL in Settings → Pages after deployment finishes.

## Preview locally

Run `python3 -m http.server 8000` in this folder, then open http://localhost:8000.
